GitHub-Pages-Dateien

1. Erstellen Sie auf GitHub ein öffentliches Repository, z. B. legal-pages.
2. Laden Sie index.html, impressum.html, datenschutzerklaerung.html und .nojekyll in das Stammverzeichnis hoch.
3. Öffnen Sie Settings > Pages.
4. Wählen Sie unter Build and deployment: Deploy from a branch.
5. Wählen Sie main und /(root), dann Save.
6. Die Startseite ist anschließend unter https://BENUTZERNAME.github.io/legal-pages/ erreichbar.
7. Diesen Link können Sie im Instagram-Profil hinterlegen.

Wichtig: Prüfen Sie vor Veröffentlichung, ob eine USt-IdNr. oder Wirtschafts-Identifikationsnummer vorhanden ist. Falls ja, muss sie gegebenenfalls in das Impressum aufgenommen werden. Die normale Steuernummer sollte nicht veröffentlicht werden.
